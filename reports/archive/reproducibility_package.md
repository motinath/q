## 3. Step-by-Step Reproduction Guide

To reproduce all benchmarks, test suites, and operational demonstrations:

### Step 1: Validate Installation
```bash
python validate_installation.py
```

### Step 2: Regenerate Benchmark Datasets (Optional)
```bash
python data/dataset_generator.py
```

### Step 3: Run Full Automated Test Suite
```bash
pytest tests/test_vector_q_suite.py tests/test_learning_flywheel_and_physics.py tests/test_advanced_features.py tests/run_basic_test.py tests/run_advanced_test.py tests/run_hardware_test.py -v
```

### Step 4: Execute Full Benchmark Evaluation
```bash
python validation_framework/benchmark_suite.py
```
This evaluates all competitors, prints summary tables, and exports `reports/benchmark_results.json`.

### Step 5: Verify Submission Readiness End-to-End
```bash
python scripts/verify_submission_readiness.py
```

### Step 6: Launch QNOC Operations Dashboard
```bash
streamlit run operations_dashboard/streamlit_app.py
```
Access the interactive operations center at `http://localhost:8501`.
